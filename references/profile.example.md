# Traveler profile — example

Copy this to `references/personal/profile.md` (git-ignored) and fill in your own details.
SKILL.md loads that file when it exists. Everything below is fictional.

## Home / origin
- Default origin: Sacramento, CA
- `origin_lat: 38.5816`, `origin_lng: -121.4944`
- Default departure on day 1: ~4:00 PM; vehicle: sedan

## Usual travel party
- Group trips: 4 adults (two couples)
- Lodging rule: sleeps 4 · minimum 2 beds · prefer 2 bedrooms
- Bed fit: `green` = meets bedroom preference, `yellow` = meets bed minimum only, `red` = below minimum

## Dietary / accessibility
- One traveler is vegetarian — every dinner shortlist needs two vegetarian-friendly picks
- No hikes over 6 miles

## Planning style
- 2-5 options per category (lodging, activities, dinners), not one fixed itinerary
- 3 day-plan variants per destination with different vibes and budgets
- End with one decision question ("Which option + which plan?")
